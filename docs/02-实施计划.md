## 1. 里程碑（严格 P0 → P1 → P2）

### M0 · Design System 基座（先做，防风格漂移）
- `app/globals.css`：实测 token 全量落地（颜色/字号/字距/圆角/阴影/曲线/层级）
- 基础原子件：`Button / IconButton / PillButton / Kbd / Avatar / StatusIcon / PriorityIcon / LabelChip / Checkbox / Tooltip / Popover / Menu / Toast / ScrollFade`
- 验收：一个 `/kitchen-sink` 内部页，所有原子件并排，肉眼确认「不刺眼、不脏、不松散」

### M1 · 全局骨架（P0）
- 双栏结构：`Sidebar(232, 可折叠) + Panel(主区)`
- 侧栏：Workspace switcher、搜索/新建圆钮、主导航（Pulse/Inbox/My issues/Reviews）、Workspace 组、Favorites 组、分组折叠
- 两条 44px 顶栏：LocationBar（面包屑 + 分页）、ViewBar（视图动作）
- 主区滚动容器独立（侧栏不跟着滚），滚动条 6px
- `⌘\` 折叠侧栏（240ms，宽度动画，无回弹）
- 验收：空主区下，截图与参考放在一起比对结构

### M2 · Command Menu + 快捷键（P0）
- `⌘K` 全局命令面板：模糊搜索议题 + 动作，分组、方向键、Enter、Esc
- 快捷键引擎：单键、和弦（G→I/B/P）、修饰键、输入框内自动失活
- `?` 快捷键面板、`G` 和弦的顶部提示
- 验收：不碰鼠标完成「搜索→打开→改状态→关闭」

### M3 · Issue List（P0，最重要）
- 按状态分组；组头（图标 + 名称 + 计数 + 折叠）32px
- 行 36px：复选框(hover/选中) → 编号 → 状态图标 → 标题 → 标签 → 优先级 → 头像 → 日期
- hover / focus / selected / multi-selected / disabled 五态齐备
- `J/K` 行导航、`X` 多选、`Shift` 范围选择、`Enter` 打开
- 筛选/排序/显示 三个 popover；视图 tabs（All / Active / Backlog）
- 批量操作浮条（底部居中）：状态、优先级、负责人、删除
- 空状态（筛选后为空 / 团队无议题两种文案）
- 行内新建（`C`）：就地插入可编辑行
- 验收：与参考截图并排；行高、字号、灰度必须一致

### M4 · Issue Detail（P0）
- 右侧抽屉（900px，overlay 240ms），`Esc` 逐层关闭
- 标题即时编辑（textarea 自适应 + `⌘Enter` 保存 + Saved 微提示）
- 描述编辑：markdown-lite + 工具条（粗/斜/行内码/列表/勾选），空态占位文案
- 右侧属性栏 286px：Status / Priority / Assignee / Labels / Project / Cycle / Due，全部可交互（下拉）
- 活动流：时间轴竖线、头像、12px 灰字、人名 510
- 评论：卡内多条 + 分隔线 + `⌘Enter` 提交 + 提交后淡入
- 验收：整体观感与参考图 1:1 对比（顶栏、正文列宽、属性列 gap 24）

### M5 · Board（P1）
- 列 = 状态，列宽 300，横向滚动 + 右侧渐隐
- 列头：图标 + 名称 + 计数 + hover 动作
- 卡片：radius 9、border、编号/标题/标签/优先级/头像
- 自研 pointer 拖拽：抓取 scale 1.02 + rotate 1.5deg + 大阴影；落点 2px 靛蓝线；160ms 归位
- 跨列拖拽改状态、同列拖拽改顺序；列计数实时联动
- 验收：拖拽录屏的手感自评（不弹、不粘、不抖）

### M6 · Projects / Settings / Login（P2）
- Projects 列表（进度条、负责人、目标日期）+ 详情（issue 列表复用）
- Settings：分栏 + 偏好项（主题、侧栏、动效强度）+ 成员表
- Login：左右分屏的品牌页（静态，可跳过进入）

## 2. 架构

```
app/
  layout.tsx                 全局字体、主题、Toast 容器
  globals.css                design tokens + 基础重置 + 滚动条
  (app)/layout.tsx           AppShell（侧栏 + 主区 + 全局浮层）
  (app)/team/[key]/page.tsx  团队视图（list ⇄ board），?issue= 打开抽屉
  (app)/projects/…           项目
  (app)/settings/…           设置
  login/page.tsx             登录
components/
  shell/    app-shell, sidebar, workspace-switcher
  topbar/   location-bar, view-bar, filter-menu, sort-menu, display-menu
  views/    issue-list, issue-group, issue-row, board, board-column, board-card
  issue/    issue-drawer, issue-title, issue-description, issue-properties, activity-feed, comment-composer
  command/  command-menu, command-items
  overlays/ help-sheet, go-to-hint, toasts
  ui/       …原子件
lib/
  types.ts, mock/*.ts, store/*.ts, shortcuts.ts, fuzzy.ts, format.ts, cn.ts
```

状态分三块（Zustand，避免一个巨型 store）：
- `useData`：issues / projects / labels / users / cycles（含所有 mutation）
- `useView`：viewMode、groupBy、sort、filters、selectedIds、activeIssueId、collapsedGroups
- `useUI`：sidebar、commandMenu、help、toasts、theme

URL 只承接「当前在哪」：`/team/[key]`、`?issue=ENG-123`、`?view=board`。其余状态留在内存（与 Linear 一致：筛选项刷新后不保留）。

## 3. 风险与对策

| 风险 | 对策 |
|---|---|
| 图标不像（Lucide 太圆润） | 状态/优先级/团队图标全部自绘 SVG，14px 网格 + 1.5px stroke；Lucide 只用于通用动作 |
| 字体没有 Inter Variable | 优先自托管 Inter Variable woff2；失败则回退系统 UI 字体并调 `letter-spacing` |
| 动效过度 | 统一走 `--t-*` / `--ease-*`，禁用 spring 默认参数；拖拽不用 dnd-kit |
| 组件各自硬编码颜色 | CSS 变量 + Tailwind 语义色别名（`text-3`、`bg-panel`），禁止裸 hex |
| 列表/看板切换闪烁 | 同一数据源 → 两套渲染，用 `AnimatePresence mode="wait"` + 80ms |

## 4. 每阶段的自检（Check）

每个里程碑结束执行：
1. `tsc --noEmit` + `next build` 必须为 0 错
2. 本地起服务 → CDP 截图（1440×900 与 1320×720 两档）
3. 与 `study/shots/ref/` 的参考图并排比对：**行高、字号、灰度、圆角、间距**
4. 输出「像不像 + 还差什么」两行结论，再进下一阶段
