# 接入你自己的模型（Agent）

这个项目**不内置任何模型、不内置任何密钥**。智能体 = 你接的模型 + 本项目的工具层。这是它和 ChatGPT / Copilot 这类产品唯一的根本差别：模型由使用者自带（BYOM），配置跟着**账号**走，不跟浏览器走。

## 三步

1. **设置 → Agents**（`/settings/agents`）
   - 先点一个预设：OpenAI / DeepSeek / OpenRouter / Moonshot / 智谱 GLM / Ollama·LM Studio / Custom（预设只填 Base URL 与推荐模型，都能手改）
   - `Base URL`：任何 OpenAI 兼容地址，例如 `https://api.openai.com/v1`、`https://api.deepseek.com/v1`、本地网关 `http://127.0.0.1:11434/v1`
   - `Model`：接口期望的模型 id（填好后点 **Test connection**，返回的模型列表会进入输入框的候选）
   - `API key`：**加密存在服务器上**（AES-256-GCM，密钥是 `.data/secret.key`），浏览器只拿到 `hasKey` 与 `sk-…abcd` 这样的提示
   - `Temperature` / `Max steps` / `Review changes` / `Instructions`（附加指令，追加在内置提示词后面）
2. 点 **Test connection**：请求 `{Base URL}/models`，返回模型数即通。
3. 两个入口：
   - **工作区会话**：`⌘J`（或侧栏「智能体」）打开一个聊天窗口，左侧是会话列表，可以开多个话题；这里问的是整个工作区（「这个周期还剩什么」），工具能改所有议题。
   - **单个议题**：议题详情里的 **Agent** 段，或在评论框以 `@agent` 开头（回车即交给它，不会当评论发出去）。

## 请求怎么走

```
浏览器 → POST /api/agent/chat（本机 Next 服务，带会话 Cookie）→ {Base URL}/chat/completions
```

三个原因走服务端代理：

- 绕开各家接口的浏览器 CORS 限制；
- **密钥不进浏览器**——服务端按会话账号取出解密后的 key 再转发，页面源码、localStorage、网络面板里都拿不到；
- 换设备登录同一账号，配置直接可用。

代理只放行 `http(s)`，挡掉 `169.254.*`、`::1`、`metadata.google.internal` 这类链路本地/元数据地址；公开部署时建议再加 `AGENT_ALLOWED_HOSTS` 白名单（见 `docs/05-部署.md`）。

## 协议要求

- `POST /chat/completions`，`stream: true` 优先；不支持流式会自动按整包 JSON 解析
- 工具调用走标准 `tools` / `tool_choice: "auto"`；模型不返回 `tool_calls` 时会直接给最终答复（不会假装改过东西）
- `Authorization: Bearer <apiKey>`
- 返回里的 `usage` 会被累计（面板底部显示「N 轮 · M 次工具调用 · K tokens」）；接口不回 `usage` 时按字符数估算

## 工具清单（模型能做的事）

| 工具 | 作用 |
|---|---|
| `list_issues` | 按关键词 / 状态 / 负责人 / 标签 / 周期筛议题 |
| `get_issue` | 读一条议题：描述、属性、子议题、关联、最近评论 |
| `create_issue` | 建议题（带 `parent` 就是子议题） |
| `update_issue` | 改状态 / 优先级 / 负责人 / 周期 / 估点 |
| `add_comment` | 以当前账号身份发评论 |
| `add_label` | 加标签，没有就新建 |
| `relate_issues` | 建关联（blocks / blocked_by / related / duplicate） |
| `list_cycles` | 列周期与窗口 |
| `list_projects` | 列项目、状态与议题数 |
| `create_project` | 建项目（名称 + 摘要） |
| `create_cycle` | 建两周周期（可选名称与天数） |
| `set_project` | 把议题放进项目 / 移出（`none`） |
| `set_cycle` | 把议题排进周期 / 移出（`none`） |
| `bulk_update` | 一次改多条：状态 / 优先级 / 负责人 |

工具改的是**服务器上的真数据**（`.data/workspace.json`，或 `WORKSPACE_MODE=personal` 时每个账号一份）。想试错就在自己的账号里试，或者先「备份 → 导出」再动手。

## 审批与留存

- 设置里的 **Review changes** 默认开启：写工具先停在「等待确认」卡片上（字段级 `In Progress → Done`），点 **Approve** 才执行，**Reject** 会把拒绝文本回灌给模型（模型不会重试同一次调用）。
- 只要一次会话落过工具，议题里会多一条以 Agent 身份写的会话卡（工具清单 + 终答），活动流也会多一条「运行了一次智能体会话」。
- 同一条议题的追问会沿用上文；`Clear` 开新会话。
- 会话日志存在 `localStorage['linear-lab:agent:sessions']`（最近 16 条会话、每条 120 行，含最近 24 条消息）；同一议题同一时刻只允许一次运行。

## 排查

| 现象 | 原因 |
|---|---|
| `401` | 密钥不对，或该接口要求其它鉴权头 |
| `403` | 该接口在你的区域不允许，或 `AGENT_ALLOWED_HOSTS` 没放行这个域名 |
| `404` | Base URL 少了 `/v1`，或该网关不提供 `/chat/completions` |
| `model not found` | `Model` 写的是展示名而不是接口 id |
| `Test connection` 通、跑起来 400 | 网关不支持 `tools`；换成支持 function calling 的模型 |
| 一直 `Thinking…` 后报错 | 上游流式被中间层截断，换非流式模型或直连网关 |
| 面板只有「配置模型后启用智能体」 | 账号里没有存 key（`hasKey=false`），或 Model 空着 |
| 「No API key stored for this account」 | 服务端没取到 key：重新保存一次，或检查 `.data/agent/<id>.json` |

## 状态

- 配置（Base URL / Model / 温度 / 步数 / 附加指令 / 加密 key）存在 `.data/agent/<账号id>.json`，**跟着账号**，换机器也在。
- 没配模型时智能体只显示一行入口，其它功能完全不受影响。
