## 验证证据

- `npx tsc --noEmit` = 0、`npm run build` = 0（每一轮均执行，最后状态同为 0）
- 真实网关联调（本地 `/v1`，`deepseek-v4.1-flash`）：`create_issue` 审批 → `get_issue` 复核；
  多轮 `update_issue`；`remember`；`search_knowledge`/`read_knowledge`；Workflow 报告 → `ENG-2`。
- 服务端调度：`daily` + 空 `lastRunAt`，**浏览器未打开**即产出 `ok` run 与 `ENG-1`。
- 命令面板：⌘K「工作流」→ 运行工作流；⌘K「发布」→ 深链知识条目并打开抽屉。
- 上下文压缩：15,580 → 11,705 tokens，无孤儿 tool 消息。
- 截图：`docs/checks/200`–`218`。

## 已知边界

- 调度租约是文件级（单机多进程）；跨主机需数据库/队列。
- 服务端工具是交互式子集（无 bulk_update / 关系 / 周期写入）。
- 附件仅文本与图片；PDF/Office 需先转文本。
- Board/List 来源 chip 的「点击过滤」与 Issue List 首屏骨架尚未做。
- 未做多工作区切换与 SSO。

**已知边界（留给后续目标）**

- 调度器依赖首个请求启动；独立进程 / 外部队列未做。
- PDF 仅支持可提取文本的英文/普通字体；CID 中文 PDF 与扫描件会明确返回空。
- 无多工作区切换、SSO、邮件邀请。
- 工作流仅时间触发，没有事件触发（如 issue 状态变化）。
