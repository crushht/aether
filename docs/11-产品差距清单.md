# 11 · 产品差距清单（对标 Linear 与 ChatGPT）

这份清单回答一个问题：**Aether 离「Linear 级的议题体验 + ChatGPT 级的 agent」还差什么。**
它只记录差距和可验证的候选任务，不记录已完成的细节（那在 `NEXT.md` 的「已完成」里）。

用法：

- `docs/11-产品差距清单.md` 的「候选队列」是自动循环的燃料：`node scripts/autopilot.mjs --seed` 会取前几条写进 `NEXT.md` 的「待办」，并从本文件删除。
- 每条候选都必须能被验证（有命令、有断言、有接口或页面），不要写「优化体验」这种无法验收的句子。
