# 13 · 持续候选池

这个文件是 `scripts/relentless.mjs` 的燃料仓：队列和 `docs/11` 都空的时候，它从**这里**搬三条进候选队列。

规则：

- 每条都必须能在一轮内做完，并且有可执行的验收方式（命令、断言、接口、页面）。
- 做完就改成 `- [x]` 并从本文件删掉，别让补货逻辑把已完成的事再搬回去。
- 顺序就是优先级：上面先做。

## 议题与规划（对标 Linear）

- [ ] P1 依赖视图：把 `blocks / blocked_by` 画成 SVG 有向图（分层布局 + 箭头），点节点打开议题抽屉；纯几何计算进 `lib/dependency-graph.ts` + 回归
- [ ] P2 收件箱稍后处理：通知菜单加「1 小时 / 明天 / 下周」，纯函数 `snoozeUntil()` + 回归；到期前不出现在未读、不计入角标
- [ ] P2 周期吞吐表：按 cycle 统计每周完成点数与平均周期，纯函数 + 一张表（与燃尽图同页）
- [ ] P2 议题模板变量：新建时替换 `{{date}}` `{{me}}` `{{week}}`，纯函数 + 回归 + 命令面板入口
- [ ] P2 看板 WIP 上限：列头显示「3 / 5」，超限变红；上限存在视图偏好里（localStorage per account）
- [ ] P2 批量改项目与周期：批量工具条新增两个选择器，复用 `bulk_update` 的语义
- [ ] P3 行内改标题：列表行双击进入编辑，Enter 保存 / Esc 取消，失焦保存
- [ ] P3 快捷键帮助补全：`?` 面板列出全部键位（含 `G` 前缀序列），与 `shortcuts.tsx` 保持同源
