# Aether v0.3.0

以 Agent 为中心的工作台：议题、项目、周期、路线图、收件箱，
加一个能读写同一工作区的智能体。**不内置任何模型** —— 填入任意 OpenAI 兼容端点即可。

## 下载

| 文件 | 适合 |
|---|---|
| `Aether-0.3.0-x64.exe` | 安装版（含开始菜单 / 桌面快捷方式，可自选安装目录） |
| `Aether-0.3.0-portable.exe` | 便携版，单个 exe，不需要安装 |

> 这两个包**没有代码签名**（证书尚未配置），首次运行 Windows SmartScreen 会拦一次：
> 点「更多信息 → 仍要运行」。

## 这一版有什么

- **工作区**：议题（列表 / 看板 / 子议题 / 关联 / 清单）、项目（健康度 / 更新 / 审计 / 导出）、周期与自动延续、路线图、Pulse、评审、收件箱、知识库、文档、全局搜索、命令面板
- **Agent**：多 Provider 与按场景路由、工具调用、写操作审批（可「总是允许」）、记忆、知识检索、工作流、用量汇总
- **可靠**：本地 JSON 快照、原子写、乐观并发、自动备份（恢复前可预览差异）
- **桌面**：窗口状态记忆、托盘、`aether://issue/<id>` 深链、更新清单检查
- **其他**：中英双语、深浅色、移动端适配（375px 起）

## 数据在哪

桌面版把数据放在 `%APPDATA%\Aether\data`，与浏览器开发模式的 `.data/` 互不影响。
浏览器模式：`npm run dev`，默认 http://127.0.0.1:4321。

## 从源码跑

```bash
npm ci
npm run dev          # 浏览器
npm run desktop:dev  # 桌面开发模式
```
