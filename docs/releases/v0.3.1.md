# Aether v0.3.1

一个补完型版本：桌面包补齐了图标与版本资源，仓库补齐了英文说明与社区文件。

## 下载

| 文件 | 适合 |
|---|---|
| `Aether-0.3.1-x64.exe` | 安装版（开始菜单 / 桌面快捷方式，可自选目录） |
| `Aether-0.3.1-portable.exe` | 便携版，单文件，免安装 |

> 仍然**没有代码签名**，首次运行 Windows SmartScreen 会拦一次：点「更多信息 → 仍要运行」。

## 这一版的变化

**桌面包**
- exe 恢复图标、`ProductName`、`FileVersion`、`CompanyName`、`LegalCopyright`（此前为绕开符号链接权限关闭了资源编辑）

**文档**
- 新增英文 README（`README.en.md`），中英文顶部互相跳转
- 新增 `CHANGELOG.md`、`CONTRIBUTING.md`、`SECURITY.md`、`CODE_OF_CONDUCT.md`
- README 增加「文档」索引：接入模型 / 部署 / 桌面应用 / 产品架构

**仓库**
- Issue 表单（bug / feature）、PR 模板、Dependabot（依赖分组升级）
- `LICENSE` 只保留标准 MIT 文本，GitHub 现在识别为 **MIT**；独立实现与 Inter 字体声明移到 `NOTICE.md`
- `docs/social-preview.png`（1280×640）与生成脚本 `scripts/make-social-preview.mjs`

## 从源码跑

```bash
npm ci
npm run dev          # 浏览器 http://127.0.0.1:4321
npm run desktop:dev  # 桌面开发模式
```

完整功能与架构见 [README](../README.md)。
